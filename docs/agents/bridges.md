Also read [Exporter workflow and engine limits](exporting.md), [Races and state](races-and-state.md#race-containers-and-opponents) for ownership/replacements, and [Decals, textures and maps](decals-textures-and-maps.md) for the shared map pipeline.

## Movable bridges

`elements/customElements/bridge` is a control-point custom element, `start` and `finish` (anchorable, also on free road ends through `roadEndAnchors`, placed one click each through `placementPoints`: the geometry script gets both at the same position until the second click, and shows only the control line then; a bridge left in that state is incomplete and deleted when its editor closes), with a mesh selector, paired/single leaves, four native behavior modes and an instance-specific preview pose. `lua/bridges.lua` generates a control line and one/two preview models through the `props` of the geometry result, never ordinary exported props (`prop_placers.export_prop_placer` skips this element). The length of the model comes from `ctx.meshSizes`. An element saved without `mesh` shows and exports `giz_bridge01_l`. Original meshes/tuning remain user-provided; no stock data is bundled. Native models have fixed dimensions: do not scale them with hinge separation. Preview matching assumes level controls; unequal heights export unchanged with a warning because the native frame has non-unit X/Y axes on slopes. LuaCSharp's `math.atan` ignores a second argument (it was the wrong preview yaw): use `math.atan2`.

Same reference executable SHA256 as [trains](trains-and-boats.md#train-splines). Loader `415400` tries the race variant then main `race/<city>/<city>_bridge[_<racetype><n>].pathset`. Manager `577a70`: two controls create one leaf, three or more create two mutually linked leaves at controls 0 and 2; control 1 and later controls are ignored. Frame `577d10` uses Z = normalize(origin - other), X = up cross Z, Y = Z cross X (X/Y not normalized). The model resolver `577e30` strips a colon/@ prefix and uses any existing PKG, falling back to `giz_bridge01_l`. Matrix `577620` reads `Size.z` (banger data +0x30) with no check: the banger manager (`440940`) returns -1 for a model without `tune/banger/<model>.dgBangerData`, so the record pointer is null and the game crashes, unlike ordinary props. `bridge_export.ensure_tuning` prevents that: stock names and files in the common folder need nothing, a city file is copied to the output (the AR packer only takes the city `geometry` and `texture` folders), as the PKG and the `_BOUND.bnd` of a city model, otherwise it generates one from the PKG bounds (CG 0, stock density 800 and `YRadius`), tracked by `.km2-bridge-tuning.json` so that it never overwrites other files. Without a PKG it reports an error and leaves the bridge out. A missing `<model>_bound` is fine: `CollisionPrim 0` falls back to a box of `Size` (`4411c0`). The custom model flow is reverse-engineered, not run in game yet. Mode `577ee0` reads only the first four characters case-insensitively: inac = closed, time = timed, prox = proximity, open = open; default timed. Neither per-path unknown nor spacing sets timing. Matrix `577620` rotates local translation (0,0,-Size.z/2) about local X then by the placement frame, with world offset (0,-0.3,0). Normal banger CG still affects the model draw transform. Animation `5776d0`: maximum 0.47123894 rad (27 deg), step 0.05/60 rad per update, 10-second waits at either end. Proximity `5780e0` checks squared distance < 10000 against player/opponent positions registered at `4132cf`/`4132fd`, not boats. Game startup also forces London bridges open under its multiplayer flag (`41330e..41335d`); do not promise per-mode control over that stock override.

`converters/generateBridgeMesh` (`replace: false`, needs a control on a road: the export JSON gives `anchor` on the points, and conversions include the roads) writes `geometry/bridge_<hash>.pkg` (named by content, so the editor reloads it; 15 characters, the limit with the behavior prefix is 32), `bound/<name>_BOUND.bnd` and `tune/banger/<name>.dgBangerData` in the city, and sets `mesh`, `generatedMesh` and `generatedLength`. Layout measured on `giz_bridge01_l` and `giz_waterloo_l` (an 18 m road with 8 m lanes and a 30 m leaf gives the bounds and section order of `giz_bridge01_l`): model y 0.3 is the hinge height, which is also the height of a road curve (top of the sidewalks, road 0.15 below); railings 0.25 wide and 1.5 high outside the road; truss 1.8 deep; a plate at road level facing down; a bottom facing down, with the truss texture; H/M/L the same and VL without railings, using the low LOD texture of the road. The road's own UV rule is not copied along it: a whole number of square tiles of the half-road and sidewalk width. Raw PKG triangles are counterclockwise from the visible side (right handed), V 0 at the road center. Both leaves share one path and so one model turned by 180 degrees (`577a70`): one cross section (the widest road) and one shear (mean angle, at most 60 degrees); only an odd tip line fits itself, so the shear goes through the center. A sheared model is longer than `Size.z` (the distance of its ends, in the generated tuning): the preview uses `generatedLength` while `mesh` equals `generatedMesh`, and the exporter warns if the hinge distance changed. Road rails (tunnels) and divider end caps (texture5) are not in the model. Checks: `python exporters/psdl/tools/_test_bridge_mesh.py`, `KM2_SELFTEST_FOCUS=bridges`. Not run in game yet.

`bridge_export.py` writes authored controls (X mirrored, paired midpoint synthesized), never preview poses, under `pathset`, with the 192-record limit. Race ownership is the ordinary stable `_propertyContainerId`; optional `replaces` references a global bridge by exported index, excludes that bridge from the race file, then includes all other city bridges. In the editor the type's `replacesReference: "replaces"` hides the replaced city bridge while its race is selected, and the field is only in the panel of race-owned bridges. Duplicate/invalid replacement references fail validation. `.km2-bridge-races.json` removes only exporter-owned obsolete race files and is excluded from AR packing. Empty city sets remove the main file. Modes, previews, replacements, tuning and native binary layout are checked by `python exporters/psdl/tools/_test_bridges.py`; editor integration (preview direction, road ends): `KM2_SELFTEST_FOCUS=bridges`. In-game moving collision, AI and pedestrian behavior remain unverified. Do not put static road collision through the moving deck.

On the maps a bridge is a closed deck between its controls (`HudmapExporter.add_bridge`, `hudmapCategory` with auto as road): on the end section of an attached road (from `anchor.insideDirection` and `totalWidth`), so it joins the road at any angle, otherwise across the hinge line with the width of the PKG, or `DEFAULT_BRIDGE_WIDTH`. Race-owned bridges are kept apart (`Shapes.with_bridges`) and drawn only on the JPG of their race, in place of the city bridge in `replaces`.
